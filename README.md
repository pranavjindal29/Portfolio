# Pranav Jindal Portfolio

A recruiter-focused portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Overview

This site is designed to present Pranav Jindal as a strong software engineer with applied machine learning experience, research depth, and product-minded frontend execution.

## Highlights

- Premium light and dark visual system
- Animated intro loader with session-aware skip behavior
- Resume-backed experience, education, and certification content
- Contact form with a real backend submission flow
- Responsive layout across mobile, tablet, and desktop
- Accessibility-minded navigation and interaction details

## Stack

- React 18
- Vite 5
- Tailwind CSS
- Framer Motion
- Lucide React
- Iconify

## Local Development

```bash
npm install
npm run dev
```

## Contact Form Setup

The portfolio includes a real contact API powered by Resend.

Create a local `.env` file with:

```bash
RESEND_API_KEY=your_resend_api_key
CONTACT_FROM_EMAIL="Pranav Portfolio <portfolio@yourdomain.com>"
CONTACT_TO_EMAIL=jindalpranav944@gmail.com
```

`CONTACT_TO_EMAIL` is optional and defaults to Pranav's portfolio email.

## Production Build

```bash
npm run build

```
